One sentence, 200 characters at most, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell.

## Entry

> Petals & Goodbyes buries dead houseplants in tiny coffins with printed eulogies, because grieving owners pay $29 for closure instead of tossing them in the bin.

## How it works

`main.py` (pure stdlib Python 3.13) writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), asserting first that it is one sentence of 1–200 characters and verifying after the write that the file matches the intended text byte for byte.
